# Rhythm Numbering


1. Quarter note
  ```markdown
  Well, you want to start at the beginning, huh?
  This is a quarter note. It is the simplest possible rhythm: one beat, nothing complicated.
  Press the play button to see and hear what a quarter note is.
  ```
  ```markdown
  Haha! Here is an exercise!
  ```
2. Quarter rest
  ```markdown
  All rests are "counterparts" of notes.
  A note and its corresponding rest form a pair with the same duration, just that there is sound for the note, but not for the rest.
  Press the play button to see what I mean.
  ```
3. Beamed eighths
  ```markdown
  Pretty boring, huh?
  Here's something to break up the monotonicity. The beamed eighth notes take up the same amount of time as the quarter, but are played twice as fast.
  ```
  ```markdown
  The metronome's speed is customizable.
  ```
4. Single eighth
  ```markdown
  This is a single eighth note.
  The duration is half a beat.
  ```
  ```markdown
  Oh yay! There are no exercises for this one!
  ```
5. Eighth rest
  ```markdown
  This is the "rest counterpart" of the single eighth note. Its duration is half a beat.
  An eighth note and an eighth rest, one after another, is not a quarter note. For the quarter note, you must hold the note for the entire beat, while you must release halfway through the beat for the eighth note + eighth rest.
  ```
  ```markdown
  More exercises for you! Hahahaha
  In one beat, you can have multiple notes. For example, in the first beat, it has a single eighth for the first part of the beat and an eighth rest for the second part.
  ```
6. Dotted eighth
  ```markdown
  When you dot something, the duration multiplies by 3/2. 
  For this dotted eighth, this means that its duration is 1/2 x 3/2 = 3/4 of a beat.
  ```
  ```markdown
  There are temporarily no practices for this one.
  ```
7. Beamed sixteenths
  ```markdown
  These sure look familiar, do they?
  Each of these sixteenth notes is 1/4 of a beat. Together, they share the 1 beat they are allotted.
  ```
  ```markdown
  And, to make sure that you understand the notes all correctly, you must get at least 80% of your practices correct!
  ```
8. Single sixteenth
  ```markdown
  This probably also looks very familiar. This is a single sixteenth note.
  Its duration is 1/4 of a beat.
  ```
  ```markdown
  You can have two, three, or four sixteenth notes beamed together as well.
  ```
9. Sixteenth rest
  ```markdown
  This is the “rest counterpart” of the sixteenth note. The rest is self-explanatory.
  ```
10. Eighth followed by two sixteenths
  ```markdown
  This is just an eighth followed by two sixteenth notes. 
  If you divide each beat into “subbeats” that are each 1/4 of a beat, then you should play for the first, third, and fourth subbeats. 
  ```
11. Two sixteenths followed by an eighth
  ```markdown
  This is similar to the previous one. Play for the first, second, and third subbeats.
  ```
12. Dotted eighth + sixteenth
  ```markdown
  Self-explanatory. Play for the first and fourth subbeats.
  ```
13. Sixteenth + dotted eighth
  ```markdown
  Play for the first and second subbeats.
  ```
14. Syncopation (sixteenth-eighth-sixteenth)
  ```markdown
  Play for the first, second, and fourth subbeats.
  ```

  ```markdown
  Watch out for other rhythms, like eighth note + sixteenth rest + sixteenth note (I'll write that with the sixteenth rest under the beam), that I didn't go over.

  ```
